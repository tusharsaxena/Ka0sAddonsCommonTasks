# Resume

`./resume-state.sh` lists each id's commit. Git is the only state; an id with nothing to do goes in `exceptions.tsv` with its reason. Interrupted item: read `git status`, finish or stash, never reset unread work. Finalize on owner go-ahead only: LibKa0s, then the addons, then this repo; `--no-ff`, delete the branch remote first.
