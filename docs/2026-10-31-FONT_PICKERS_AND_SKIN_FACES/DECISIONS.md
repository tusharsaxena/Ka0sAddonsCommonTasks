# Decisions

Owner rulings are marked; everything else is the lead's call and may be overruled.

- **D-01 cause (measured).** The owner's `_retail_/Fonts/FRIZQT__.TTF` has the same sha256 as `Prototype-Regular.ttf`, so every client Friz key draws Prototype on that machine. Real Friz comes from `Interface/AddOns/DialogueUI/Fonts/frizqt__.ttf`. WoW Default moves to `Ka0s Friz Quadrata TT` so it differs from Ka0s Default whatever the client's file holds. The owner's client file is left alone.
- **D-02 owner ruling.** All four Segoe UI weights ship, told of the Microsoft ownership, the public repos and 3.7 MB per addon. Not re-litigated. Same for Friz, Doris PP, Emblem and Avant Garde.
- **D-03 owner ruling.** Every font change gets size normalization against Ka0s Prototype.
- **D-04 sources.** Under `/mnt/g/Games/Blizzard/World of Warcraft/_retail_/Interface/AddOns/`: Sorted/Textures (segoeui, segoeuib, segoeuisl, seguisb, OpenSans-Regular/Bold/CondBold/Light/Semibold), DialogueUI/Fonts/frizqt__.ttf, AbstractFramework/Media/Fonts/Emblem.ttf (233 glyphs, unrestricted fsType, over the 232-glyph ChonkyCharacterSheet copy), SharedMedia/fonts/doris_pp/DorisPP.ttf, EllesmereUI/media/fonts/Avant Garde Naowh.ttf.
- **D-05 keys.** `Ka0s Friz Quadrata TT`, `Ka0s Segoe UI`, `Ka0s Segoe UI Bold`, `Ka0s Segoe UI Light`, `Ka0s Segoe UI Semibold`, `Ka0s Open Sans`, `Ka0s Open Sans Bold`, `Ka0s Open Sans Condensed`, `Ka0s Open Sans Light`, `Ka0s Open Sans Semibold`, `Ka0s Emblem`, `Ka0s Doris PP`, `Ka0s Avant Garde`. `Ka0s Prototype` already ships. "Segoe UI Light" is the Semilight file and "Open Sans Condensed" the CondBold file, matching the keys the owner sees from Sorted.
- **D-06 faces.** Body, title and HUD: WoW Midnight Segoe UI Semibold (title Segoe UI Bold), Azeroth Open Sans Semibold (title Open Sans Bold), Ember Emblem, High Contrast Doris PP, Glass Avant Garde, WoW Default Ka0s Friz. The last three-plus-Ember have one weight, so their titles use the same face larger.
- **D-07 widths.** Each skin's body, title and HUD sizes keep the existing parity test against Prototype 12/14, measured from the shipped bytes. New: a per-face width table for shipped faces, so a font override of a Ka0s face also scales to Prototype's width. A non-Ka0s LSM face is unmeasurable in game and stays unscaled.
- **D-08 picker.** SharedMediaWidgets is absent from BankLedger, DropWatcher, LootHistory, PGFE, PrettyChat, QuickComms, WhatGroup and the Skin Tester, so the library ships self-contained `Ka0sMedia_*` AceGUI types copying AbsorbTracker's picker: each row drawn in its own face, or with its bar, border or background swatch. The Skin tab always uses them (they take the leading "Skin's default (X)" row); an `LSM30_*` row falls back to them when that type is not registered. A plain Dropdown over media keys is a finding.
- **D-09 pull-outs.** The skin rule that SharedMediaWidgets pull-outs are never restyled stands; the Ka0s picker's own pull-out is the library's, so it wears the skin.
- **D-10 outline.** Default applies to an owner that never set one; a stored choice stays. An addon default that stores "all" moves to the new default.
- **D-11 branch and tag.** `feat/2026-10-31-font-pickers-skin-faces` stacks on the unmerged 2026-10-30 run in all 19 repos; `bases.tsv` pins that head. Local tag v1.83.0; v1.82.0 is left as it is, both pushed at finalize. The earlier run's merge also waits for this smoke.
- **D-12 README.** Font licensing and font credit text leaves every README; `media/fonts/FONTS.md` takes the record with the license files. Icon credits stay. No GitHub issues are planned.
