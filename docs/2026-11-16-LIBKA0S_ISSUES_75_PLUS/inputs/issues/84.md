# #84 Ka0s Default: alternating table row stripe is barely visible

## What happens

Under the **Ka0s Default** skin, a table's alternating row stripe is barely visible. The striped rows are almost the same shade as the plain ones, so the eye can't follow a row across a wide table.

Seen in Combat Trail's Results window (Fights tab, four rows, Ka0s Default, 2026-11-13): the rows read as one flat block, and only the selected row's highlight stands out. Other skins draw the stripe clearly.

## Expected

The alternating stripe is visible at a glance on every skin, Ka0s Default included, without competing with the hover or selected row highlight.

## Where to look

- Ka0s Default's token for the alternate row fill (its value or alpha against the window background)
- Whether the stripe is drawn over a background that already has low opacity, which flattens the contrast further
- Consider a check in the skin tester that compares the stripe and plain row colors on each skin and flags a pair too close to tell apart

## Reported from

Combat Trail (vendors LibKa0s v1.94.0).
