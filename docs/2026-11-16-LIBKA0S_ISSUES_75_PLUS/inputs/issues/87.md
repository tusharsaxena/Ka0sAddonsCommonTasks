# #87 Standardize sample character names, classes and specs across all Ka0s addons

### Description
Each addon makes up its own sample characters for test mode, sims and showcases (Combat Trail uses Samplehunter and Mockarrow on Samplerealm, with the pet Grimfang). Define one shared set of sample character names, realms, classes, specs and pet names that every Ka0s addon uses, so samples look the same everywhere.

### Motivation
Consistency across the collection: the same sample characters in every addon's test mode, screenshots and docs.

### Proposed behavior
- **Two character sets**, one for Retail and one for WoW Forever, since the clients' classes, specs and talent trees differ (Forever uses talent trees such as Beast Mastery / Marksmanship / Survival).
- **A naming convention** for sample names (characters, realms, pets, guilds), so new ones fit the set and can't be mistaken for real players.
- **Where it lives:** in WowAddonStandards, where every addon can find it, and possibly exposed as data in LibKa0s so addons read it instead of copying it. _TBD_ which, or both.
