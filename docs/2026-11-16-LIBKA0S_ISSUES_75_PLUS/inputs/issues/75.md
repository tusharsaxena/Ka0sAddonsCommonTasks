# #75 Test kit: unregisterAll can skip listeners mid-dispatch, and registered frames get garbage-collected

## Summary

Two bugs in the vendored test kit make consumer suites flaky. Neither affects the game client. Both were found while converting Outfitter Reborn, at v1.85.0 (kit rev 50).

### 1. `Callbacks:unregisterAll` can skip listeners during a dispatch

`testkit/mock_ace.lua:116-117` clears every list unconditionally:

```lua
for _, list in pairs(self.events) do list[target] = nil end
for _, list in pairs(self.queue or {}) do list[target] = nil end
```

In Lua 5.1, assigning nil to a key that isn't there still inserts it, and the table may rehash. When that happens to the list `Callbacks:fire` is walking with `next()`, the walk ends early and later listeners are never called.

The real CallbackHandler guards this (`if callbacks[self] then callbacks[self] = nil end`, CallbackHandler-1.0.lua:183-184).

**Repro in Outfitter:** `tests/test_bar.lua` "bar: a profile switch redraws the bar from the new profile and rebinds the triggers" fails about 1 run in 8-20. The trigger binder's PROFILE_CHANGED handler calls `UnregisterAllMessages` on its targets, and the bar's PROFILE_CHANGED listener is then skipped.

**Fix:** guard both lines (`if list[target] ~= nil then list[target] = nil end`). With the guard, a scratch copy passed 80 of 80 runs, against about 10 failures in 80 without it.

### 2. Frames held only by weak registries are garbage-collected

`frameSet` (`mock_base.lua:259`) and `eventRegistry` (`:415`) are weak-keyed. A frame that a suite registers for events but does not hold itself is freed by the next GC cycle, and its events silently stop arriving. A real client never frees frames.

Outfitter worked around this in its own suite (commit 0694218, `tests/test_mock_gear.lua` listener). Any consumer can hit the same thing.

**Suggested fix:** strongly hold a frame while it has a live event registration.

## Acceptance

- [ ] Guard the two unregisterAll lines and add a kit regression test (an unregisterAll during a fire must not skip a listener).
- [ ] Keep registered frames alive, with a regression test (register, collectgarbage, fire, then the frame receives the event).
- [ ] Bump the kit revision and re-vendor consumers.
