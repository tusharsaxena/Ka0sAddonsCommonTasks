# #81 LibKa0s-Launcher: let an addon add extra menu entries

LibKa0s-Launcher-1.0 (minor 9, v1.94.0) has a fixed `ENTRIES` table: Enabled, Locked, Test mode, Sim mode, Show window. launcher-§2 forbids an addon building its own menu. As a result, Ka0s Skill Master can't add the **Journal** entry its approved mockup shows after Show window. That gap is recorded under Known Limitations in the addon's ARCHITECTURE.md.

Proposal: an optional `extraEntries = { { label, checked = fn|nil, onClick = fn } }` field on the launcher descriptor. The entries would be appended after Show window in declared order and skinned like the built-in ones. launcher-§2 would then need a matching amendment.
