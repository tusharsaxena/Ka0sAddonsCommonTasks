# #89 Adopt the v2.110.0 Widgets Footer (24 px, CombatTrail look) in every addon window with a footer

## What
Adopt the v2.110.0 **Footer** in every Ka0s addon window that has a footer, when it re-vendors LibKa0s **v1.103.0** or later (Widgets minor 27).

The standard (WowAddonStandards v2.110.0, standalone-windows "The footer" and "Window chrome geometry", skinning-§4/§7, anti-pattern #118) now requires any window footer to be built with `W.Footer(parent, opts)`. It uses the CombatTrail look:
- no fill band;
- a 1 px hairline in `divider` along the top;
- `foot.left` and an optional `foot.right` in `text.muted`;
- an optional right-hand slot of catalog marks (`opts.marks`);
- the resize grip in the bottom-right corner (`opts.resize` / `opts.grip`).

The height is `W.FOOTER.HEIGHT` = **24 px** and is skin-invariant. A hand-built footer, a dark footer band or another height is anti-pattern #118.

## Per addon
Replace each hand-built footer or status bar with `W.Footer`, keep its text, tooltips and controls, set the body's bottom inset to the footer height, and update the smoke checks and docs. Mark an addon N/A if it has no footer.
