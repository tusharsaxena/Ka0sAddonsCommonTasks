# DropWatcher: skin defaults

Adopted (`Skin:RegisterOwner` at core/SkinSetup.lua:496, 23 owner tokens `dw.*` in `NS.SKIN_TOKENS` core/SkinSetup.lua:107-160), master @ 755157c. Guard: `Kit.skinValues` (tests/run.lua:281-291) allows the calls Colored, Escape and tone, plus 4 host rows (the RollCells DICE, COIN, DE and CROSS group-loot art, cause A6). `Kit.skinSwitch.surfaces` (tests/skin_switch_facts.lua:121-228, wired at tests/run.lua:296) declares 23 surfaces (title bar, active and idle tabs, restricted badge, test-mode word, flat button, row chevron, column head and band, detail card box, footer hairline, Drops row stripe and tone, tables' shadow, icon border, both glows, group header, History's column head, Offer panel, tooltip lines, Insights card, heading and divider, bar, strip column, toast). Not declared: the Rolls panel, the Roll popup card, History, Pending and compact rows, the compact filters button, the Edit message box, the scrollbars, the trade countdown bar and track, and the Drops empty state. DropWatcher creates no StatusBar and never calls `SetStatusBarTexture`; its only textured bars are the Insights bars, which LibKa0s-Charts draws through `S.BarTexture` (libs/LibKa0s/Charts.lua:351-352, the host passes no `barFill`), so the Combat Trail statusbar-texture trigger has no DropWatcher counterpart.
